## 2. Theorem V: re-derivation

Setting: L full-dimensional polytope in R^n; NS = {x : f_i(x) >= 0, i = 1..m} bounded, L subset NS; every f_i >= 0
defines a facet P_i = L cap {f_i = 0} of L.

**Lemma 1.** A facet F = L cap {b.x = c} (b.x <= c valid on L) that is not a positivity facet is strictly violated by a
vertex of NS, and every such vertex lies outside L.
*Proof (re-derived).* NS is a polytope, so NS = conv(vert NS).  If no vertex violates b.x <= c, the inequality is valid
on NS and F_NS := NS cap {b.x = c} is a face of NS containing F, so dim F_NS >= n - 1.  It is proper: L is
full-dimensional and b != 0, so b.x < c somewhere on L subset NS.  NS is full-dimensional (it contains L), so F_NS is a
facet of NS.  For a full-dimensional polyhedron {x : f_i(x) >= 0}, every facet is NS cap {f_i = 0} for at least one i
(each facet is induced by an inequality of any defining system; e.g. Schrijver, Theory of Linear and Integer
Programming, Thm 8.1).  Hence F subset L cap {f_i = 0} = P_i, two facets of L with F subset P_i, so F = P_i: a
contradiction.  The second statement is trivial (b.x <= c is valid on L).  QED

**Lemma 2.** For every point y the set Vis(y) of facets of L strictly violated by y induces a connected subgraph of the
facet-ridge graph of L.
*Proof (re-derived).* Take z in int L and the polar L* = {g : g.(x - z) <= 1 on L}, a polytope.  Facets F (b.x <= c) of
L correspond to the vertices g_F = b / (c - b.z) of L* (c - b.z > 0 since z is interior), ridges of L to edges of L*
(face lattices are anti-isomorphic).  With phi(g) = g.(y - z): phi(g_F) > 1 iff b.y > c, so Vis(y) = {vertices with
phi > 1}.  If a vertex v of L* is not phi-maximal, some edge at v increases phi (L* subset v + cone(edge directions at v);
if every edge direction had phi <= 0 then phi <= phi(v) on L*).  Following improving edges from a vertex with phi > 1
stays in {phi > 1} and ends in the phi-maximal face M (finitely many vertices, phi strictly increasing).  M is a polytope
whose graph is connected and whose edges are edges of L*; all its vertices have phi = max >= phi(v) > 1.  Hence any two
vertices of {phi > 1} are joined inside {phi > 1}.  QED

**Theorem V.** If K contains all positivity facets, (i) every non-positivity facet in K has all its ridge-neighbours in
K, and (ii) every vertex of NS outside L violates a facet of K, then K = all facets of L.
*Proof (re-derived).* Let U be a non-positivity facet.  By Lemma 1 some vertex w of NS violates U, w not in L.  By (ii)
w violates some K0 in K.  w is in NS, so it violates no positivity inequality; the facet inequality of P_i is f_i >= 0
up to a positive factor (facet inequalities of a full-dimensional polytope are unique up to scaling), so no positivity
facet lies in Vis(w).  By Lemma 2 there is a path K0 = F_0, ..., F_r = U of ridge-neighbours inside Vis(w); inductively
each F_t is in K and is not a positivity facet, so by (i) F_{t+1} is in K.  QED

**Application to (2,2,4).**  (a) n = 48, L full-dimensional (affine rank 48 of the 256 deterministic points), NS bounded
(it is determined by 64 probabilities in [0, 1]); (b) all 64 positivity inequalities define facets of L (own exact rank
check, logs/IND_classes.log); (c) G acts by affine bijections of the no-signalling affine space mapping deterministic
points to deterministic points and positivity forms to positivity forms, hence preserves L, NS, facets and ridges; so
for a G-invariant K it suffices to check (i) on one representative per class and (ii) on one vertex per G-orbit.

**Gaps found: none in the mathematics.**  Remarks for the write-up (no effect on correctness):
1. Remark (d) of CLOSE_NOTES ("for every d the non-local vertices of NS(2,2,d) are the PR_k", attributed to Barrett et
   al. 2005) is not needed for d = 4: the vertex set is computed exactly (CLOSE_verify.py (B), (B'); independently here,
   Sec. 4).  For other d it is a literature input and should be cited as such.
2. Remark (f) is right: if L cap {f_i = 0} were lower-dimensional the inclusion F subset L cap {f_i = 0} is impossible,
   so only "positivity facets" that are facets matter.  For (2,2,4) all 64 are facets anyway.

## 3. Hypothesis (i): independent expansion of the 33 non-positivity classes

Method (IND_expand.py).  For the class representative F (tight set T, |T| = 55..160):
1. (h0, h) is recomputed in our coordinates from the slack tensor (exact solve, checked on all 256 points); a
   coordinate j with h_j != 0 is dropped, so T projects injectively into R^47 (exact affine rank 47 checked).
2. All facets of conv(T) (= ridges of L inside F) by IND_dd.py: Motzkin double description written from scratch,
   int64 with the certified bound |ray entry| <= 2^27 (so every combination is < 2^63), exact combinatorial adjacency
   test (two variants: rarest-constraint lists, and a 'neighbourhood' scan using that any ray containing
   Z(p) & Z(q) shares >= n-2 zeros with p), a random or index-ordered initial basis and min |R+||R-| insertion.
   Every output ray is re-verified: valid on all of T, tight set equal to the tracked one, rank of the tight rows
   = 47 (modular rank, which is a lower bound of the rational rank and cannot exceed 47 for a nonzero ray; exact
   python-flint rank otherwise -- never needed), pairwise distinct.
3. Rotation: with s_g the ridge functional extended to all 256 points and s_F the slack of F,
   theta* = max_{lam not in T} (-s_g/s_F) (exact), neighbour slack = den s_g + num s_F (primitive), checked >= 0,
   zero on the ridge and on a point off F.
4. Classification: a cheap G-invariant selects candidate classes; an explicit g in G with g.s' = s_rep is found by an
   exhaustive search (pair-hash pruning that can only remove non-matching pairs, then entry-by-entry comparison of all
   256 values, re-verified in numpy).  No neighbour may stay unmatched (it would be a NEW class).

Nature of the evidence.  Soundness of every reported ridge and neighbour is certified exactly (rank certificate of
each ridge, explicit relabelling of each neighbour).  Completeness of each ridge list rests on the correctness of the
double description algorithm (Motzkin; adjacency test of Fukuda-Prodon), now implemented twice independently
(dd_numba.py / CLOSE_dd_safe.py of the original run, and IND_dd.py with a different data layout, two adjacency-test
variants, other insertion orders and other initial bases); for every class the two computations give the same number
of ridges and the same neighbour-class distribution.  Two further independent consistency checks: (a) double counting
orbit_i a_ij = orbit_j a_ji with our own orbit sizes, which a missing ridge between listed classes would violate;

## 5. Ratio certificates (IND_sdp.py, IND_sdp_test.py)

Model (re-derived).  For PVMs on Phi_D, <Phi_D| A (x) B |Phi_D> = tr(A^T B)/D, so p(ab|xy) = tau(P^x_a Q^y_b) with
P = (A^x_a)^T, Q = B^y_b projections in one algebra M_D and tau = tr/D (no commutation).  With
U_g = sum_a i^a P^g_a (g = 0, 1: Alice; 2, 3: Bob): p(ab|xy) = (1/16) sum_{n,m} i^{-na-mb} tau(U_x^n U_{2+y}^m);
balanced marginals <=> tau(U_g^n) = 0 (n = 1, 2, 3).  Reversal symmetry is WLOG: the direct sum of the strategy and its
transpose (dimension 2D, balanced, same behaviour; transposition reverses words) has moments
(tau(w) + tau(reverse w))/2.  Level-2 moment matrix on the 121 words of length <= 2 (adjacent letters from different
generators): M[u,v] = tau(u* v) depends on the dihedral class of the cyclically reduced word; M >= 0, M[u,u] = 1,
identity class 1, single-letter classes 0, class(neg w) = conj class(w); 1 269 real variables t_r, |t_r| <= 1.
Certificate: for symmetric Z' (dyadic) and s >= 0 with Z' + sI >= 0, with e_r = <Z', Emb F_r> + c_r,
beta <= c0 + <Z', Emb M0> + sum |e_r| + 2 N s (exact rationals); Z' + sI >= 0 is certified as L'L'^T + E with L' a
dyadic (2^-40) rounded Cholesky factor of Z' + (s/2) I and E exactly diagonally dominant with nonnegative diagonal.
For class j, beta_j = -slack_j and R_j(p) = 1 + beta_j(p)/slack_j(u) <= 1 + UB_j/slack_j(u).
kappa_4 = I_ME(4)/2 enclosed in arb: [1.44812160922935 +/- 6.2e-15]; the rigorous lower bound 1.448121609 is used.

Validity tests (IND_sdp_test.py, numerical): for random balanced PVMs on Phi_4 and a rank-2 example on Phi_8 the
symmetrised moments are class-consistent to 4e-15, M >= 0 up to -4e-15, and the relaxation objective equals the

## 6. Consequences

  by independent code (Secs. 3, 4) and Theorem V is re-derived (Sec. 2); the orbit sizes (exhaustive stabilisers,

* **Theorem D4** (C2 at d = 4).  For a balanced max-ent behaviour p (PVMs, any local dimension D) and a facet beta,
  R(beta; p) = (beta(p) - beta(u)) / (beta_L - beta(u)) is G-invariant, so by F4 it suffices to bound each class:
  positivity R <= 1; class 17 = CGLMP_4 (explicit relabelling, IND_sdp_test.py): R_17 = I_4(g.p)/2 <= I_ME(4)/2 =
  kappa_4 with equality iff p is a relabelled DKZ behaviour (max-ent CGLMP optimality and rigidity, Theorems 1 and 2; not
  re-checked here); every other class: certified R_j < kappa_4 (Sec. 5).  Hence v_c(p) = min(1, 1/max_beta R(beta; p))
  >= 1/kappa_4 = 2/I_ME(4) = 0.6905497..., with equality iff p is DKZ up to relabelling.  Lemma CG (THEOREM.md Sec. 4a,
  re-derived: refine each projector into a basis of its range; the coarse-graining maps L into L, the refined noise
  u onto p_A (x) p_B) extends v_c >= 2/I_ME(4) to all PVMs on Phi_4.
* Gap corollary (own bounds): if the critical facet of a balanced max-ent behaviour is not a CGLMP_4 copy, then
  v_c >= 1/1.4142621 = 0.707095.
* Not re-checked here: max-ent CGLMP_4 optimality with rigidity (Theorems 1 and 2 of the main result).
