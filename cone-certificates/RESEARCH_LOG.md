## 4. Complete proofs of the cell-embedding reduction (2026-09-30, write-up)
Setting.  (M_M, tau = Tr/M); Q_x (x in Z_N, N = 4d) projections, {Q\_{r+jd}}\_{j in Z_4} a PVM for each residue r; A_x = Q_x, B_x = Q\_{x+d},
C_x = 1 - A_x - B_x (so A_x B_x = 0); k(u) = cot(pi u/N); <A,B>\_tau = sum\_{x,y} k(x-y) tau(A_x B_y); Phi_N = <[0,d),[-d,0)> (block value);
F = <A,B>\_tau/2 - d/2 (E2-R2), F_DKZ = Phi_N/2 - d/2.  T(m) = sum_y tau(A\_{y+m} B_y), N(m) = T(m) - T(-m).
(i) Linear form of the target.  k is odd and k(N/2) = 0, so <A,B>\_tau = sum\_{m=1}^{2d-1} k(m) N(m); QD-L7 gives N(2d-m) = N(m), N(d) = d,
  hence <A,B>\_tau = d + sum\_{m=1}^{d-1} v_m N(m), v_m = k(m) + k(2d-m) = cot(pi m/4d) + tan(pi m/4d) = 2 csc(pi m/2d); the block has N(m) = m.
  So <A,B>\_tau - Phi_N = sum_m v_m delta_m, delta_m = N(m) - m.
(ii) Cell inequality (QD2-L1).  Fix ell_0..ell\_{d-1} >= 0 with sum d, ell_x := ell\_{x mod d}, L_0 = 0, L\_{x+1} = L_x + ell_x (L_N = N),
  I_x = [L_x, L\_{x+1}) on T_N = R/NZ, A~(xi) = A_x, B~(xi) = B_x for xi in I_x.  Then B~ is a projection-valued step field, 0 <= A~ <= 1 - B~,
  int\_{T_N} B~ = sum_x ell_x Q\_{x+d} = sum_r ell_r sum_j Q\_{r+(j+1)d} = d 1 and likewise int A~ = d 1.  Rescaling T_N to the unit circle,
  Q^ell := int int tau(A~(xi) B~(eta)) cot(pi(xi-eta)/N) dxi deta = N^2 int tau(A~ g) dm  (g = conjugate function of B~), so Q-T1 (which
  uses (\*) pointwise for the M x M pair (B~(t), g(t)); only the trace constraints alpha = beta = 1/4 enter) gives Q^ell <= N^2 Phi_c(1/4,1/4).
  (The double integral converges absolutely: same-cell terms vanish since A_x B_x = 0; adjacent cells give integrable corner singularities.)
  Q^ell = sum\_{x,y} K^ell(x,y) tau(A_x B_y) with K^ell(x,y) = G(L\_{x+1}-L_y) - G(L_x-L_y) - G(L\_{x+1}-L\_{y+1}) + G(L_x-L\_{y+1}),
  G'' = cot(pi ./N), G(u) = -(N^2/2pi^2) Cl2(2 pi u/N) (2nd antiderivative; linear terms cancel).  Equality for every window: the window
  [c,c+d) and [c-d,c) occupy [L_c, L_c + d) and [L_c - d, L_c) (each window contains each residue once), adjacent arcs of length d, whose
  continuum value is N^2 Phi_c (Stein-Weiss extremal).  The rotated configuration Q'\_x = Q\_{x-c} is again of 27B type, so
  sum\_{x,y} K^ell(x+c,y+c) tau(A_x B_y) <= N^2 Phi_c for every c; K^ell is invariant under (x,y) -> (x+d,y+d), and averaging over c gives
  sum_m Kt(m) T(m) <= N^2 Phi_c, Kt(m) = (1/d) sum\_{r<d} K^ell(r+m, r) (odd in m); folding as in (i): <u^ell, delta> <= 0 with
  u^ell_m = Kt(m) + Kt(2d-m), with equality at every window (delta = 0).
(iii) Window-sum form (QD2-L2): K^ell(r+m, r) = G(S_r(m+1)) - G(S_r(m)) - G(S\_{r+1}(m)) + G(S\_{r+1}(m-1)), S_r(k) = L\_{r+k} - L_r, and
  S\_{r+d} = S_r, so Kt(m) = Delta^2 P(m), P(k) = (1/d) sum_r G(S_r(k)).  For 0 <= j <= d, S_r(2d-j) = d + S_r(d-j) = 2d - S\_{r+d-j}(j), hence
  P(2d-j) = (1/d) sum_r G(2d - S_r(j)) and u^ell_m = Delta^2_m (1/d) sum_r Ghat(S_r(m)), Ghat(u) = G(u) + G(2d-u), m = 1..d-1.
(iv) Conclusion (QD2-R1).  If v = sum_k lambda_k u^{ell^(k)} with lambda_k >= 0 (CONE_d), then <A,B>\_tau - Phi_N = sum_k lambda_k <u^{ell^(k)}, delta>
  <= 0, i.e. F <= F_DKZ, for every configuration for which (\*) holds pointwise (all M if (\*) holds; M <= 4 by Qs-T1/Qg-T2b; direct sums
  of such blocks, since then B~(t) and g(t) are block diagonal and both sides of (\*) are additive over blocks).
(v) Dirichlet(1) identity (QD2-L3).  For ell = d \* Dir(1,..,1): S(m)/d ~ Beta(m, d-m), density of S(m) = ((d-1)/d) b\_{m-1,d-2}(s/d)
  (b\_{k,n}(x) = C(n,k) x^k (1-x)^{n-k}).  From b''\_{m,d} = d(d-1)(b\_{m-2,d-2} - 2 b\_{m-1,d-2} + b\_{m,d-2}):  Delta^2_m p_m(s) = d^2/ds^2 [b\_{m,d}(s/d)]
  for 2 <= m <= d-2; for m = 1 (resp. d-1) the point mass of S(0) = 0 (resp. S(d) = d) cancels exactly the boundary term
  [phi d/ds b\_{m,d}(s/d)] at s = 0 (resp. d) of the integration by parts (d/ds b\_{m,d}(s/d) = [m=1] at 0, -[m=d-1] at d).  Hence for every
  phi in C^2(0,d] with integrable phi'' s^m:  Delta^2_m E phi(S(m)) = int_0^d phi''(s) b\_{m,d}(s/d) ds = (d/(d+1)) E phi''(dB), B ~ Beta(m+1,d-m+1).
  With phi'' = 1/s: int_0^1 b\_{m,d}(x) dx/x = C(d,m) B(m, d-m+1) = 1/m exactly.  []
