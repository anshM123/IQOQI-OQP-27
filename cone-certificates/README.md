# The cone condition CONE_d for every d (computer-assisted)

CONE_d says that the explicit vector v, with v_m = 2 csc(πm/(2d)), lies in the convex cone generated by the cell-embedding
vectors u^ℓ. Each u^ℓ is built from Clausen functions. Combined with the cell inequalities ⟨u^ℓ, δ⟩ ≤ 0, CONE_d gives
⟨v, δ⟩ ≤ 0, which is the CGLMP bound for d outcomes. This folder certifies CONE_d for every d ≥ 2.

## Reproduce

Requirements: Python 3 with `mpmath` and `numpy` (`scipy` only for re-generating LP candidates). Run, from this folder:

    python audit_alld.py

It prints the margins of every regime and ends with `ALL-D CERTIFIED (every d >= 2)`. The expected output is in
`logs/audit_alld_final.log`.

To re-run the certifiers themselves:
- **LP certificates, d ≤ 200:** `python lp_reverify.py $(seq 2 200)` re-verifies the stored certificates in `certs/` with
  `verify_cone.py`. `python run_verify.py d0 d1` regenerates certificates: an untrusted LP search proposes columns, then a
  rigorous verification runs.
- **Gaussian certificates, 201 ≤ d ≤ 2000:** `python verify_cert.py d` writes `logs/cert_g_d{d}.json`, and
  `python audit_cert_g.py` audits all 1800. A full run takes about 12 CPU-hours; `bash start_cert.sh 14` runs it on 14
  parallel workers.
- **Analytic regime, d ≥ 2001:** `python run_alld.py 12` re-runs the scripts `a01`–`a14` and `t35_polya.py`, writing
  `logs/alld/`. Then run `python audit_alld.py`.

## The three regimes

| Range | Method | Certified margins |
|---|---|---|
| 2 ≤ d ≤ 200 | exact finite representations v = Σ λ_k u^{ℓ_k}: rational cells (all ≥ 1/16) and certified weights λ_k > 0, verified in `mpmath` interval arithmetic (`verify_cone.py`; Clausen function by its Bernoulli series with a rigorous tail; exact residual correction) | min d·λ_k = 0.0816 |
| 201 ≤ d ≤ 2000 | Gaussian-modulated Dirichlet cell processes (`CONE_PROOF.md`, Lemmas R1–R4), with a fixed point by the Poincaré–Miranda theorem (Lemma B). One certificate per d from the single-run checker `verify_cert.py`, at 160 bits, with one code version and one box. Factorials are exact, zeta values are rigorous enclosures, and no decision uses floats (`RIGOR_GAUSS.md`) | d²·min a_k ≥ 0.06319 (even d), 0.12638 (odd d); d·min Δ²W ≥ 0.660; derivative ratio ≥ 4.0009 (1 needed) |
| d ≥ 2001 | a uniform analytic argument: a smooth model, interval Taylor models over ε = 1/d ∈ [0, 1/2001], and certified error terms (`CONE_ALLD_PROOF.md`, `RIGOR_ALLD.md`) | a_k ≥ 0.1186944·w_k·ε²; Δ²W ≥ 0.620154·ε; log-margins of the tail and fixed-point terms > 800 |

For d ≥ 201 the certificates give v = E_Π[u^ℓ] + Σ_s w_s t_s, where Π is a probability measure on cell vectors with all cells
positive, w_s ≥ 0, and t_s = e_s + e_{d−s}, which is itself a two-residue cell direction. By Carathéodory's theorem this is a
finite nonnegative combination of cell vectors, so it is CONE_d in the finite form. For d ≤ 20, CONE_d is also proved in Lean
([`../lean/`](../lean/)), with certificates re-evaluated by the Lean kernel.
